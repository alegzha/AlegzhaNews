# Новинний бот для Telegram «Алєгофренський Вісник»

Збирає новини про ігри, важку й альтернативну музику, кіно й серіали, софт і штучний інтелект,
переписує їх українською і публікує окремими постами з картинкою й посиланням на джерело.
Працює безкоштовно: GitHub Actions + Cloudflare Workers + безкоштовні ліміти Gemini.

## Що вміє

- **Новини** з RSS-стрічок, сторінок сайтів без RSS, профілів Bluesky і Bloomberg (з фільтром за темами).
- **Переклад** через Gemini Flash (стиль українського медіа, словник термінів); запасні — Gemini Flash-Lite, DeepL, Google.
  Українські джерела публікуються без змін.
- **Посилання на Steam** у назвах ігор.
- **Вішліст Steam** — пости, коли гра вийшла або отримала знижку (ціни в ₴).
- **Релізи тижня** — щопонеділка о 10:00: ігри з вішліста й найочікуваніші релізи Steam.
- **Spotify** — нові альбоми, EP і сингли виконавців, на яких ти підписаний.
- **Відсіювання повторів** — та сама новина з різних сайтів (і різними мовами) виходить один раз.
- **Сповіщення про поломки** в особисті та **тижневий звіт** (скільки постів з яких джерел, хто мовчав, хто перекладав).
- **Пульт у Telegram** (воркер Cloudflare): «Новини зараз», список джерел, додати/прибрати джерело, релізи тижня, стан запусків.

## Як усе влаштовано

| Частина | Де | Що робить |
|---|---|---|
| `bot.py` | GitHub Actions (`.github/workflows/news.yml`) | збирає джерела, перекладає, публікує, зберігає `state.json` |
| `feeds.yaml` | репозиторій | джерела, рубрики, фільтри, ліміти, налаштування вішліста/Spotify |
| `steam.py`, `wishlist.py`, `releases.py`, `spotify.py`, `alerts.py` | репозиторій | посилання на Steam, вішліст, релізи тижня, Spotify, сповіщення |
| `worker/worker.js` | Cloudflare Worker `alegzhanews` | таймер запусків кожні 30 хв, пульт у Telegram, проксі для сайтів, вхід у Spotify |

Воркер оновлюється автоматично: кожна зміна в репозиторії сама публікується на Cloudflare (Workers Builds, `wrangler.toml`).
Запуски: основний — таймер воркера кожні 30 хвилин; запасний — розклад GitHub раз на 3 години.

## Секрети

**GitHub** → репозиторій → Settings → Secrets and variables → Actions:

| Назва | Для чого |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота від @BotFather |
| `TELEGRAM_CHANNEL_ID` | канал (`@назва` або `-100…`) |
| `TELEGRAM_ADMIN_ID` | твій Telegram id — сповіщення й тижневий звіт |
| `TELEGRAM_WISHLIST_CHAT_ID` | *необов'язково:* куди слати пости про вішліст, якщо не в канал |
| `GEMINI_API_KEY` | основний перекладач (aistudio.google.com/apikey, безкоштовно) |
| `DEEPL_API_KEY` | *необов'язково:* запасний перекладач |
| `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SPOTIFY_REFRESH_TOKEN` | нові релізи зі Spotify |

**Cloudflare** → Workers → `alegzhanews` → Settings → *Variables and Secrets* (не плутати з блоком у Builds):
`TG_TOKEN`, `GH_TOKEN` (fine-grained, Actions і Contents: Read and write), `WEBHOOK_SECRET`, `GH_REPO`, `OWNER_ID`,
`SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, *необов'язково* `PROXY_HOSTS`. Детальніше — `worker/README.md`.

## Налаштування (`feeds.yaml`)

Редагувати можна на GitHub (файл → ✏️ → Commit changes) або з Telegram (➕ Додати / ➖ Прибрати).

**Джерело** — запис у рубриці `categories.<рубрика>.feeds`:

```yaml
- name: Назва
  url: https://site.com/feed/
  lang: uk                      # українською — без перекладу
  include_tags: ["Ігри"]        # лише статті з цими тегами RSS
  exclude_tags: ["Реклама"]
  include_keywords: ["Nintendo", "Xbox"]   # лише заголовки з цими словами
  exclude_keywords: ["AI"]
  max_per_run: 1                # не більше N за перевірку (типово limits.max_per_source_per_run)
  max_per_day: 5                # не більше N на добу
  alt_urls: [https://site.com/rss]          # запасні адреси стрічки
  type: html                    # сайт без RSS: бот читає сторінку…
  link_pattern: '/news/\d+-'    # …і бере посилання за цим шаблоном
```

Профіль Bluesky — `url: https://bsky.app/profile/<нік>/rss` (заголовком стає перше речення поста).

**Інші блоки:**
- `filters.skip_keywords` — слова в заголовку, через які новина не публікується; `filters.steam_ignore` — слова, які не робити посиланням на Steam.
- `wishlist` — профіль Steam, регіон (`UA`), мінімальна знижка, що повідомляти.
- `weekly_releases` — день і година «Релізів тижня», скільки ігор Steam показувати.
- `spotify` — хештег, скількох виконавців перевіряти за запуск, наскільки свіжі релізи.
- `fetch_proxy` — адреса проксі воркера для сайтів, що блокують GitHub (сайти дозволено в `PROXY_HOSTS` воркера).
- `limits` — постів за перевірку (15), з одного сайту (5), вік новин (12 год), довжина опису (450).

## Стиль постів

Емодзі рубрики + заголовок жирним (назви ігор — посилання на Steam) → короткий опис → 🔗 джерело → хештег рубрики
(#ігри, #музика, #кіно_і_серіали, #софт, #ШІ). Правила перекладу й словник термінів — `GEMINI_PROMPT` у `bot.py`.

## Ручний запуск

- Telegram: кнопка **🔄 Новини зараз** або **📅 Релізи**.
- GitHub: Actions → News to Telegram → Run workflow (галочка — опублікувати «Релізи тижня» зараз).

## Якщо щось не так

- **Сповіщення «Джерело не працює»** — сайт змінив адресу RSS або блокує GitHub: додай `alt_urls` або сайт у `PROXY_HOSTS` воркера.
- **«Gemini більше не перекладає»** — закінчився денний ліміт; бот перекладає запасними сервісами, ліміт оновиться наступної доби.
- **«Spotify недоступний»** — онови `SPOTIFY_REFRESH_TOKEN` через `https://alegzhanews.alegzha.workers.dev/spotify/login`.
  Якщо Spotify просить зачекати (обмеження частоти), бот сам робить паузу.
- **Кнопки в Telegram не відповідають** — напиши боту `/start`; перевір `GH_TOKEN` у воркері.
- **Лог запуску** — GitHub → Actions → потрібний запуск → run → Fetch, translate and post (або кнопка ℹ️ Стан у Telegram).
