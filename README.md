# Новинний бот для Telegram

Що робить бот:
- кожні 30 хвилин збирає новини про ігри, важку й альтернативну музику, кіно та серіали;
- перекладає їх українською і публікує окремими постами з картинкою, описом і посиланням на джерело;
- у новинах про ігри робить назви ігор посиланнями на Steam;
- раз на годину звіряється з вішлістом Steam і пише, коли гра вийшла або отримала знижку (ціни в гривнях, регіон Україна).

Працює безкоштовно на GitHub Actions, комп'ютер вмикати не треба.

---

## Крок 1. Telegram: бот і канал

1. Відкрий свій канал → **Керування каналом → Адміністратори → Додати адміністратора**.
2. Знайди свого бота за @юзернеймом і дай йому право **«Публікувати повідомлення»**.
3. Запиши адресу каналу:
   - публічний канал: `@назва_каналу`;
   - приватний канал: перешли будь-який пост із каналу боту **@userinfobot** або **@getidsbot**,
     він покаже id вигляду `-1001234567890`.

## Крок 2. Steam: відкрити вішліст

Steam → твій профіль → **Редагувати профіль → Налаштування приватності** →
**«Інформація про ігри» = Відкрито**.

Без цього бот не побачить вішліст. Новини працюватимуть, а в логах буде попередження.

Твій профіль уже вписано в `feeds.yaml` (`https://steamcommunity.com/id/alegzha/`).

## Крок 3. GitHub: репозиторій

1. Зареєструйся або увійди на **github.com**.
2. Натисни **+ → New repository**. Назва — будь-яка (наприклад, `news-bot`), тип **Private**.
   Натисни **Create repository**.
3. Завантаж файли.

   **З комп'ютера (найпростіше):**
   розпакуй архів, на сторінці репозиторію натисни **uploading an existing file**
   (або **Add file → Upload files**), перетягни **вміст** папки `news-bot`
   (файли `bot.py`, `steam.py`, `wishlist.py`, `feeds.yaml`, `requirements.txt`, `README.md`
   і папку `.github`), потім натисни **Commit changes**.

   > Папка `.github` на macOS і в Linux прихована. На Mac натисни `Cmd + Shift + .`,
   > щоб її побачити. Без неї розклад не запуститься.

   **З телефона:** завантаж звичайні файли через **Add file → Upload files**.
   Файл розкладу створи вручну: **Add file → Create new file**, у полі назви введи
   `.github/workflows/news.yml` (слеші самі створять папки) і встав вміст цього файлу з архіву.

## Крок 4. GitHub: секрети

Репозиторій → **Settings → Secrets and variables → Actions → New repository secret**.
Додай:

| Назва | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота від @BotFather |
| `TELEGRAM_CHANNEL_ID` | `@назва_каналу` або `-100…` з кроку 1 |
| `TELEGRAM_WISHLIST_CHAT_ID` | *необов'язково:* куди слати пости про вішліст, якщо не в канал (див. нижче) |
| `TELEGRAM_ADMIN_ID` | *необов'язково:* твій Telegram id — сюди бот пише, якщо щось зламалось |
| `GEMINI_API_KEY` | *необов'язково:* ключ Gemini з aistudio.google.com/apikey — основний перекладач (безкоштовно) |
| `DEEPL_API_KEY` | *необов'язково:* ключ DeepL API Free для якіснішого перекладу | (запасний) |

Токен ніде, крім секретів, не публікуй.

**Пости про вішліст собі в особисті:** напиши своєму боту `/start`, дізнайся свій id
у @userinfobot (число без мінуса) і впиши його в `TELEGRAM_WISHLIST_CHAT_ID`.
Без цього секрету вони йдуть у канал.

## Крок 5. GitHub: дозволи та перший запуск

1. **Settings → Actions → General → Workflow permissions** → вибери
   **Read and write permissions** → **Save**. Без цього бот не зможе запам'ятовувати, що вже публікував.
2. Вкладка **Actions**. Якщо GitHub питає, чи вмикати workflows, погоджуйся.
3. Зліва вибери **News to Telegram** → **Run workflow** → **Run workflow**.
4. Через 1–3 хвилини відкрий запуск → **run** → крок **Fetch, translate and post** і подивись лог:
   - `✅ PC Gamer: нових N` — джерело працює;
   - `❌ …` — джерело недоступне, бот його пропускає;
   - `🕹 Steam: …` — знайдено гру для посилання;
   - `Вішліст: профіль … → SteamID …` і `Вішліст: перевірено N ігор` — вішліст підключено.

Перший запуск публікує до 5 найсвіжіших новин і лише запам'ятовує стан вішліста,
щоб у канал не прилетіла пачка старих знижок. Далі бот працює сам кожні 30 хвилин.

## Налаштування (`feeds.yaml`)

Редагувати можна прямо на GitHub: відкрий файл → ✏️ → **Commit changes**.

- **Джерела** — додай або прибери RSS-стрічки в рубриках `games`, `music`, `movies`.
- **`skip_keywords`** — слова в заголовку, через які новина не публікується.
- **`steam_ignore`** — слова, які бот помилково зробив посиланням на Steam.
- **`steam_links: false`** у рубриці `games` вимикає посилання на Steam.
- **`wishlist`**:
  - `min_discount` — мінімальна знижка для поста (зараз 10%);
  - `notify_release` / `notify_discount` — увімкнути чи вимкнути пости про релізи та знижки;
  - `check_every_minutes` — як часто перевіряти вішліст;
  - `country: UA` — регіон цін (Україна, гривні).
- **`weekly_releases`** — пост «Релізи тижня»: `weekday` (день), `hour` (година за Києвом),
  `top` (скільки найочікуваніших ігор Steam), `enabled: false` — вимкнути.
- **`limits`** — скільки постів за раз, з одного сайту, наскільки свіжі новини.

## Як працюють пости про вішліст

- 🚀 **Вийшла** — гра була «Скоро» і стала доступною.
- 🔥 **Знижка** — з'явилась знижка від `min_discount` або вона збільшилась.
  Показуються ціна в гривнях, стара ціна і дата завершення акції.
- Повторно про ту саму знижку бот не пише. Якщо акція закінчиться і почнеться знову, пост буде.
- Ігри, щойно додані у вішліст, бот спершу запам'ятовує і пише про них лише при наступних змінах.

## Релізи тижня

Щопонеділка о 10:00 (налаштовується) бот публікує список ігор, що виходять у найближчі 7 днів:
⭐ з твого вішліста (з ціною в гривнях) і 🔥 найочікуваніші релізи Steam.
Ігри, для яких Steam знає лише місяць чи квартал, не потрапляють у список.
Опублікувати просто зараз: **Actions → News to Telegram → Run workflow** → постав галочку
**«Опублікувати „Релізи тижня“ зараз»** → **Run workflow**.

## Сповіщення про поломки

Якщо заданий секрет `TELEGRAM_ADMIN_ID`, бот пише тобі в особисті:
- ⚠️ джерело не відповідає або віддає порожню стрічку понад 12 годин;
- ⚠️ закінчився місячний ліміт DeepL або не працює жоден перекладач;
- ⚠️ не вдається публікувати в канал;
- ⚠️ вішліст Steam недоступний понад 6 годин;
- ❌ запуск упав повністю — з посиланням на лог.

Коли проблема зникає, приходить ✅ «Відновилось». Нагадування про ту саму проблему — не частіше раза на добу.
Свій id можна дізнатися, написавши боту `/start` (якщо підключена кнопка) або в @userinfobot.

## Якщо щось не так

- **Нічого не публікується** → перевір, що бот адмін каналу і секрети названі точно як у таблиці.
- **`chat not found`** у лозі → неправильний `TELEGRAM_CHANNEL_ID` (для приватного каналу потрібен `-100…`).
- **`Вішліст порожній або приватний`** → крок 2.
- **Помилка при `git push`** у кроці *Save state* → крок 5.1.
- **Ціни не в гривнях** → у лозі буде попередження; перевір `country: UA`.
- GitHub може запускати розклад із затримкою 5–15 хвилин, це нормально.
- Якщо в репозиторії 60 днів немає змін, GitHub вимикає розклад. Бот сам зберігає стан,
  тож репозиторій лишається активним. Якщо розклад усе ж зупиниться, у вкладці Actions буде кнопка, щоб увімкнути його знову.
